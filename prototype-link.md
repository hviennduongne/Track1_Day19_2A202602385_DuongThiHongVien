# Hướng dẫn mở Prototype

Prototype được build bằng HTML/CSS/JS thuần, chạy trực tiếp trên trình duyệt, không cần cài đặt Node.js hay API.

## Cách 1: Mở file nội bộ (Local)

1. Clone repo này về máy.
2. Mở file `prototype/index.html` trực tiếp bằng trình duyệt (Chrome, Edge, Safari...).
3. **Để hiện Annotation cho Facilitator (ẩn với Tester):** thêm `?facilitator=1` vào cuối thanh địa chỉ. Ví dụ: `file:///.../prototype/index.html?facilitator=1`

## Cách 2: Qua link GitHub Pages (Dành cho Tester)

`[CẦN ĐIỀN: Link GitHub Pages chung của nhóm, sau khi repo được push lên GitHub và bật Pages]`

> **Lưu ý Facilitator:** Khi gửi link cho tester, **KHÔNG** kèm `?facilitator=1` để tránh tester đọc được kỳ vọng của nhóm. Facilitator nên mở một tab riêng có `?facilitator=1` để tự theo dõi kịch bản.
